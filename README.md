Entry for the [The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36)
competition on make.fun: one line, under 200 characters, that someone could
send to call in sick — the funniest excuse they can land in one breath,
judged pairwise by an AI comedy editor on whether a boss might half believe
it, whether the idea is fresh, and whether the laugh arrives before the last
word.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. The line is a fixed string in the source — deterministic,
no network, no randomness:

> My back went out this morning — my mattress folded me in half and kept the receipt. Can't sit up, let alone sit through standup.

A bad back is the most half-believable excuse there is; the mattress
"keeping the receipt" makes it fresh instead of a worn-out ailment, and the
last word does the work twice — standup is the meeting you can't sit
through, and sitting is exactly what a bad back won't let you do. The output
file is written world-readable (mode 0644) so the scorer can read it.

## Run it

```sh
python3 main.py
```
